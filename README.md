# PicoPlay — компактный контроллер Яндекс Музыки для Windows

<img width="1671" height="941" alt="PicoPlay" src="https://github.com/user-attachments/assets/e1399565-f85e-49d0-b5a2-aeb59d0827de" />

PicoPlay — небольшое плавающее окно для управления уже запущенной Яндекс Музыкой. Приложение использует медиасессию Windows и не требует входа в аккаунт Яндекса.

## Возможности

- воспроизведение и пауза, предыдущий и следующий трек;
- перемотка текущего трека;
- регулировка громкости отдельной аудиосессии Яндекс Музыки;
- компактный режим и три фиксированных размера окна;
- горячие клавиши с возможностью перенастройки;
- сохранение положения окна и прозрачности.

## Скачать и запустить

Скачайте `PicoPlay.exe` из списка файлов этого релиза и запустите его. Затем откройте Яндекс Музыку и включите воспроизведение — PicoPlay подключится к медиасессии Windows.

Это автономная сборка для Windows x64: устанавливать .NET отдельно не нужно.

## Конфиденциальность

PicoPlay не запрашивает пароль, cookies или токены Яндекса. Управление выполняется через медиасессию Windows.

## Примечания

- Визуализатор временно отключён.
- Регулировка громкости Яндекс Браузера отключена: Windows управляет звуком браузера целиком, а не отдельной вкладки.
